# Coordinates

A tiny iPhone-friendly web app that shows your live GPS position in:

- **Decimal degrees** (6 dp, ≈1 m precision)
- **Degrees / minutes / seconds** (e.g. `31° 57′ 12.34″ S`)

Plus accuracy, altitude, copy-to-clipboard, an Open-in-Maps link, and a full-height **South** alignment arrow.

## Use on iPhone

1. Open the GitHub Pages URL in Safari
2. Share → **Add to Home Screen**
3. Allow location when prompted

No build step, no dependencies — it's a single `index.html`.
